# Security reporting

This repository is an early local prototype. Read the
[security model](docs/security-model.md) before using real knowledge. There are
no supported releases, response-time guarantees or production security claims.

No private reporting address or enabled private reporting channel has been
verified for this project. Do not post secrets, private knowledge, exploit
details or sensitive logs in a public issue or pull request. The verified
project location is the
[WormVolt GitHub repository](https://github.com/captains-deck/wormvolt); this
document does not claim its private vulnerability-reporting feature is enabled.

Owner action: enable GitHub private vulnerability reporting or supply a verified
private contact, then document that channel here. Until one is established,
withhold sensitive details and use only a non-sensitive request to establish a
channel through an already trusted relationship with the owner. No address is
invented here.

Once a private channel is confirmed, a useful report includes affected revision,
platform, expected and observed behaviour, a minimal synthetic reproduction and
impact. Remove credentials and private payloads. Coordinate disclosure with the
owner and do not test against systems or data you are not authorized to access.
